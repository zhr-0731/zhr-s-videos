# 张皓然的视频作品集网站

## 🎯 网站概述

**网站标题**：张皓然的视频作品集
**定位**：个人视频作品展示平台
**风格**：现代化深色主题，渐变背景，毛玻璃效果

## 🎨 设计特色

### 视觉设计

- **配色方案**：
  - 主色调：渐变紫色 (#6a5af9 → #d66efd → #ff8ed4)
  - 平台专属色：B站蓝 (#00a1d6)、抖音黑 (#121212)、微博红 (#e6162d)、微信绿 (#07c160)
- **背景**：渐变深色背景 + 动态风景图
- **字体**：Noto Sans SC (思源黑体)，确保中文字体显示效果

### 交互效果

- 毛玻璃效果 (backdrop-filter)
- 悬停动画和过渡效果
- 响应式设计，适配各种屏幕尺寸
- 平滑滚动和动态元素
